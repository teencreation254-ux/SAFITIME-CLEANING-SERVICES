# Safitime Cleaning Services Website

A responsive static website for Safitime Cleaning Services, ready to publish using GitHub Pages.

## Files
- `index.html` — website content and booking form
- `style.css` — layout, colors, responsive styling
- `script.js` — mobile navigation and booking email behavior

## Publish using GitHub Pages
1. Sign in to https://github.com or create an account.
2. Click **New repository**.
3. Name the repository `safitime-cleaning-services`.
4. Set it to **Public**, then create the repository.
5. Upload `index.html`, `style.css`, and `script.js` to the repository root.
6. Open **Settings → Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Select branch **main** and folder **/(root)**, then click **Save**.
9. Wait a few minutes. GitHub will show your published website address in the Pages section.

## Booking form note
The booking form uses a `mailto:` link. It opens the visitor's email application with the booking details filled in; the visitor must press **Send**. It does not silently send or store booking submissions. For guaranteed online submissions, connect a form backend or email form service later.

## Before publishing
- Confirm the contact number and email are correct.
- Replace the sample photos if you have Safitime's own photos. Current images are hosted on Unsplash and need an internet connection.
- Test the site on a phone and computer.
